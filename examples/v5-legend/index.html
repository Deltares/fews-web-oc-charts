v5: headless legend

This application-owned HTML legend uses the core model, not a legend plugin. Toggle a layer to restack the areas and autoscale the value axis. Parent checkboxes show partial visibility. Isolation affects siblings at the selected hierarchy level. Library-rendered SVG swatches show each mark's styles, including the dashed line with markers and multicolour stack groups.

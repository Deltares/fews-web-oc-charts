v5: headless legend

The application-owned HTML legend uses the core model directly; the button can also install the optional built-in SVG renderer. The Observed and Forecast root entries are legend groups (legendGroup option) that toggle all their marks together. Toggle a layer to restack the areas and autoscale the value axis. Parent checkboxes show partial visibility. Isolation affects siblings at the selected hierarchy level. When enabled, choose a docked or corner-overlay position for the built-in SVG legend. Library-rendered SVG swatches show each mark's styles, including the dashed line with markers; group headings show a layers icon. Click a built-in swatch or label to toggle visibility; dimmed entries are hidden. Turn off group headings to show only individual series and layers.

Public API

const builtIn = legend({ position: 'top', showGroups: false })
const plot = createPlot(host, { scales, axes, marks, plugins: [builtIn] })
builtIn.update({ showGroups: true })
// Built-in entries toggle on click or Enter/Space; opacity shows visibility.

const entries = plot.legend.entries.get()
const swatch = createLegendSwatch(entries[0].symbol, { width: 36, height: 20 })
label.append(swatch) // Application-owned label and layout.
// Framework renderers can use typed geometry instead of DOM elements.
const primitives = legendSymbolPrimitives(entries[0].symbol, { width: 36, height: 20 })

plot.legend.toggle(entries[0].id, 'external')
plot.legend.isolate(entries[0].id, 'external')
plot.legend.showAll('external')

// Marks sharing a legendGroup are nested under one toggleable root entry.
series(store, { label: 'Observed total', legendGroup: 'Observed', ... })
stackedArea(table, { label: 'Contributions', legendGroup: 'Observed', ... })

// Direct handle updates also refresh the legend.
observed.update({ visible: false })

  console.log(event.detail.source, event.detail.changes)

v5: interactive zoom

Zoom the chart with the mouse wheel. Choose which scale directions respond and whether Ctrl or Shift is required. Double-click inside the plot to restore the initial domain.

const interaction = zoom({ mode: 'x', wheel: 'x', modifier: ModifierKey.Ctrl })
const plot = createPlot(host, { scales: { t, q }, axes, marks, plugins: [interaction] })
interaction.update({ mode: 'xy', wheel: 'xy' }) // update the mounted behavior
// Wheel over the plot to zoom; double-click inside the plot to reset.

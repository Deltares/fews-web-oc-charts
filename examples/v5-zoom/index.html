v5: interactive zoom

Zoom the chart with the mouse wheel. Choose which scale directions respond and whether Ctrl or Shift is required. Double-click inside the plot to reset the selected directions using the chosen policy. Options apply immediately without recreating the plot.

Public API

    
const interaction = zoom({ mode: 'x', wheel: 'x' })
const plot = createPlot(host, { scales: { t, q }, axes, marks, plugins: [interaction] })
interaction.update({ mode: 'xy', wheel: 'xy' }) // both axes respond to the wheel
interaction.update({ wheel: 'none', reset: 'toggle' }) // double-click remains enabled
plot.on('domainchange', ({ scale, domain, source, explicit }) => {
  console.log(scale, domain, source, explicit) // one event per changed scale
})
// Wheel over the plot to zoom; double-click inside the plot to reset.

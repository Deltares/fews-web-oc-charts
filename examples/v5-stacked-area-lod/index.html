v5: stacked-area LOD

A 24,000-sample diverging stack demonstrates shared-boundary level of detail. As the visible window gets denser than four samples per plot pixel, the renderer retains bucket endpoints, boundary extrema, sign transitions, gaps and viewport neighbours using one row selection for every layer in the stack.

Both boundaries of this implicit stack use exactly the same retained sample rows. Drag the slider to compare a sparse view with a dense full-series view; resize the page to see the pixel-bucket budget adapt to plot width. Linear and midpoint-step curves share the selected rows in both SVG and canvas. Switch renderers without replacing the data. The displayed row count is estimated from SVG path commands and is unavailable in canvas mode.

Public API

const areas = stackedArea(data, {
  x: 'sample',
  scales: { x: 'sample', y: 'flow' },
  layers: [
    { id: 'base', y: 'base', fill: '#4477aa' },
    { id: 'adjustment', y: 'adjustment', fill: '#228833' },
  ],
})
// Dense stacks automatically share screen-space retained rows.
areas.update({ curve: 'step' })
areas.update({ renderer: 'canvas' }) // undefined restores SVG

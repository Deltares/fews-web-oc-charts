v5: polar progress marks

Progress marks draw rounded angular intervals centered on radial values. The interval and radial center contribute to autoscaling; thickness is measured in pixels.

Public API

const completed = progress({
  x: 'completion',
  y: 'track',
  xValues: [[0, 72], [0, 45], [0, 89]],
  yValues: [25, 50, 75],
  thickness: 18,
})

v5: grouped and stacked bars

Four SVG plots share one aligned table of irregular time intervals. Positive and negative values accumulate independently. A missing visible layer gaps only its own stack; hiding it repairs that stack. Grouped layers and named stacks keep their slots when hidden.

Update retained handles

The table owns its columns. Appends update all four plots and retain the newest eight intervals. Layer visibility and ordering change derived endpoints without changing source values. These controls exercise the public mark API, not a built-in legend or hit testing. Canvas and stacked-area rendering remain separate work.

Public API

const flows = createTable({ t, end, upstream, lateral })
const bars = bar(flows, {
  x: 't',
  scales: { x: 't', y: 'q' },
  layout: 'stacked',
  interval: { start: 't', end: 'end' },
  layers: [
    { id: 'upstream', y: 'upstream', stack: 'observed', fill: '#4477aa' },
    { id: 'lateral', y: 'lateral', stack: 'observed', fill: '#228833' },
  ],
})
// Omit all stack IDs for one implicit stack.
// Use layout: 'grouped' (without stack IDs) for independent layer slots.
// Horizontal bars keep scales.x as the category binding and scales.y as value.
bars.update({ groupPadding: 0.2 })
flows.append({ t: [nextStart], end: [nextEnd], upstream: [6], lateral: [-2] })

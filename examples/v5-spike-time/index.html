v5 spike: time zones and DST

The spike's Intl prototype resolves local-hour boundaries to UTC instants. Nonexistent hours are omitted; repeated hours appear twice with their UTC offsets to distinguish them. The line uses epoch milliseconds, so its x spacing represents elapsed time.

Phase 0 prototype. The tick table exposes the time-zone results directly; this is not the final multi-level time-axis API.

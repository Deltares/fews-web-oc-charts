v5: line, markers and area

One data-backed series mark combines a line, point markers and a filled area to a configurable baseline. The missing interval stays a gap in all three layers.

Toggle layers through the retained mark handle, or append and replace data through its columnar store. The time domain is updated explicitly; automatic extents, canvas rendering and interactive mark behavior remain separate work.

const data = createSeries({ x: times, y: discharge })
const observed = series(data, {
  x: 't',
  y: 'q',
  line: { width: 2 },
  markers: { size: 4 },
  area: { to: 0, opacity: 0.2 },
})
observed.update({ markers: false })

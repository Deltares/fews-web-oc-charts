v5: line, markers and area

One static series mark combines a line, point markers and a filled area to a configurable baseline. The missing interval stays a gap in all three layers.

Phase 2 series marks are static: provide aligned x/y values and replace the mark to change them. Automatic extents, data stores and interactive mark behavior are planned separately.

Public API

line({
  x: 't',
  y: 'q',
  xValues: times,
  yValues: discharge,
  markers: { size: 4 },
  area: { to: 0, opacity: 0.2 },
})

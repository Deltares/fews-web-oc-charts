v5: current time

Mark the current time on time axes. Both plots follow one shared clock, which the application starts and stops. Hover over the triangle below the line to see the time.

Clock

Public API

const clock = sharedClock({ interval: 1000 })
clock.start()

createPlot(host, {
  scales: { time: timeScale({ timeZone: 'Europe/Amsterdam' }), level: linearScale() },
  plugins: [currentTime({ clock, label: 'hover' })],
})

// Without a clock, the plugin updates itself every 10 seconds.
currentTime()

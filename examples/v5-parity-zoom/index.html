v4/v5 parity: zoom

Wheel over either chart to zoom at the cursor. Change these options without recreating either plot; disabling the wheel still allows double-click reset. The charts share data and controls, not domains.

Intentional differences

    
    
      
  • 
        Wheel step sizes and axis padding differ: compare affected directions and behavior, not
        identical domain endpoints.
      
    • 
      
  • 
        v4 resets both axes. v5 resets only the selected direction. Neither version requires the
        wheel modifier for double-click reset.
      
    • 
      
  • 
        v4 toggle alternates initial and full extents. v5 toggle first shows the full extent, then
        restores the previous zoomed domain. Initial reset restores v5 y autoscaling; zooming y
        makes its domain manual until reset.
      
    • 
      
  • 
        The second half of the series is higher and outside the initial time window. v4 excludes
        this continuation from initial autoscaling but includes it in full reset; v5 starts with an
        explicit time window and autoscales visible values. v4's time-axis toggle compares Date
        objects by identity and may stay at the initial time extent; the numeric y axis demonstrates
        its initial/full toggle.
      
    • 
      
  • 
        v4 reports zoom/reset callbacks. v5 reports one domainchange per changed scale with wheel,
        reset, autoscale or API source; the readout retains the latest event for each scale. No
        event is emitted when the domain is unchanged.
      
    • 
      
  • 
        v4 also supports drag selection in ZoomHandler. In v5 this is a separate brush plugin; see
        the brush parity example.
      
    • 
    

    
Native v5 API

    
const interaction = zoom({ mode: 'x', wheel: 'x', reset: 'initial' })
interaction.update({ mode: 'xy', wheel: 'xy', modifier: ModifierKey.Shift })
interaction.update({ wheel: 'none' }) // double-click reset remains available
interaction.update({ reset: 'toggle' })
plot.on('domainchange', ({ scale, domain, source, explicit }) => {
  // Update application-owned readouts; explicit distinguishes manual domains from autoscaling.

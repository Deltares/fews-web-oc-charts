v5: synchronized live stream

Two differently sized plots share one following time scale, one value scale, a pointer and a selection. Every batch appends four one-minute samples to a retained series (1,440 points) and a retained aligned table (720 rows). The overview stacks the table; the detail groups it as bars. Old rows are evicted without growing the canonical buffers.

Drag to pan or scroll to zoom: either gesture suspends follow for both plots while data keeps arriving. Double-click or press Resume follow to jump back to the latest two hours. Move over either plot to share the crosshair; Shift-drag to share a time selection. Scroll the detail out of view (or pause it) to suspend its rendering: it catches up with one render of the latest state when visible again. Destroying the detail leaves the overview, the data and the shared handles running.

const t = timeScale({ timeZone: 'UTC', follow: { window: '2h' } })
const q = linearScale({ domain: [-3, 10] })
const level = createSeries(history, { maxPoints: 1440 })
const flows = createTable(rows, { x: 't', maxPoints: 720 })
const pointer = sharedPointer({ by: 'xy' })
const selection = sharedSelection()
const panning = pan({ mode: 'x' })
const zooming = zoom({ mode: 'x', wheel: 'x' })
const plugins = () => [
  panning, zooming,
  crosshair({ pointer, labels: { x: 't', y: 'q' } }),
  brush({ mode: 'x', persistent: true, selection }),
]
const overview = createPlot(elA, {
  scales: { t, q }, marks: [stackedArea(flows, ...), series(level, ...)], plugins: plugins(),
})
const detail = createPlot(elB, {
  scales: { t, q }, marks: [bar(flows, { layout: 'grouped', ... }), series(level, ...)], plugins: plugins(),
})

batch(() => { level.append(next); flows.append(nextRows) }) // one follow update
t.following.get()     // false after a pan/zoom in either plot
t.resumeFollow()      // or double-click: back to the latest window
detail.pause()        // manual pause; off-screen plots pause automatically
detail.resume()       // one catch-up render of the latest state
detail.destroy()      // overview, stores and shared handles keep running

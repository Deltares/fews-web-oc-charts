v5: polar range marks

Polar range marks map angular and radial interval pairs to annular sectors. Multiple marks can be layered with independent fill and opacity.

Interval endpoints contribute to autoscaling on both polar scales. The angles below are bearings in degrees; the radial intervals use the configured numeric scale.

Public API

const sector = range({
  x: 'bearing',
  y: 'distance',
  xValues: [[20, 75], [120, 175]],
  yValues: [[25, 65], [40, 85]],
  fill: '#1677a6',
  opacity: 0.3,
})
const plot = createPolarPlot(element, {
  scales: { bearing: angular(), distance: radial() },
  marks: [sector],
})

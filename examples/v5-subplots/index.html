v5: stacked subplots

Two vertically stacked subplots share one UTC time scale. Discharge is shown above rainfall, each with its own y-axis and domain. Rainfall bars extend down from zero on a reversed y-axis. Both plots resize to the available page width.

Shared x-scale, independent y-scales

const t = timeScale({ domain: [start, end], timeZone: 'UTC' })
const q = linearScale({ domain: [0, 80] })
const rain = linearScale({ domain: [0, 10], reverse: true })

// Pass the same time-scale handle to both plots.
createPlot(topHost, { scales: { t, q }, ... })
createPlot(bottomHost, { scales: { t, rain }, ... })

// Updating t.domain updates both plots. Each y-domain is independent.
// Host sizes are observed automatically; no fixed plot width is needed.

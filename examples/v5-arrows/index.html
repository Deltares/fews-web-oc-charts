All examples Cartesian and polar ranges

v5: arrows

Compare endpoint-based vectors in Cartesian coordinates and polar coordinates. Each arrow connects its supplied start and end values; polar endpoints follow the plot's angular scale, including its direction and intercept.

Public API

arrows({
  x: 'time', y: 'value',
  xValues: starts, yValues: startValues,
  xEndValues: ends, yEndValues: endValues,
  color: '#1677a6', headSize: 9,
})

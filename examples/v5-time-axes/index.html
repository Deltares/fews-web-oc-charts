v5: civil-time axes

Automatic time ticks follow local calendar boundaries. Switch between the 2026 spring-forward and fall-back transitions to see missing and repeated local hours; change the axis time zone and locale without changing the shared instant domain.

Phase 1 public API: this example renders scales, axes and layout only. Marks and interactive zoom are not available yet.

Public API

const t = time({ domain: [from, to], timeZone: 'UTC' })
const timeAxis = axis('t', {
  position: 'bottom',
  timeZone: 'Europe/Amsterdam',
  locale: 'en-GB',
})
createPlot(element, { scales: { t }, axes: [timeAxis] })

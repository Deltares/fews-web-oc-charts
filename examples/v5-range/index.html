v5: cartesian range marks

Each pair of x and y intervals produces a rectangle. The ranges contribute both endpoints to autoscaling, and a gap in either interval omits that rectangle.

Range marks accept numeric intervals on linear or time scales. One mark represents one independently styled range layer; use multiple marks for different fills and opacity.

Public API

const forecast = range({
  x: 't',
  y: 'q',
  xValues: [[start, end], [nextStart, nextEnd], null],
  yValues: [[low, high], [nextLow, nextHigh], [low, high]],
  fill: '#1677a6',
  opacity: 0.25,
})
const plot = createPlot(element, {
  scales: { t: time(), q: linear() },
  marks: [forecast],
})

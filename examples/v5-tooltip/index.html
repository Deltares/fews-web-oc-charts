v5: tooltip

Inspect samples with matching symbols and label colors. Crosshair axis callouts show shared coordinates without repeating them in every tooltip entry.

Tooltip options

Advanced: tooltips across shared-time subplots

Each mark type has its own subplot and value scale, while all three plots share the same UTC time-scale handle. Hover any panel: the pointer time is relayed to the other panels, showing an x crosshair and mark-specific tooltip in all three. The line, rainfall bars and stacked area each resolve values against their own mark and y scale.

Advanced shared-x setup

const t = timeScale({ domain: [start, end], timeZone: 'UTC' })
const flow = line({ x: 't', y: 'q', xValues: times, yValues: discharge })
const rain = bar(rainfallData, {
  x: 'start', y: 'rainfall', scales: { x: 't', y: 'rain' },
  interval: { start: 'start', end: 'end' },
})
const components = stackedArea(flowData, {
  x: 't', scales: { x: 't', y: 'flow' }, layers,
})
const guide = crosshair({ mode: 'x', labels: { x: 't' } })

// Install the same x-only guide in each plot. Relay pointer time between SVGs,
// projecting it with each plot's t binding; each tooltip stays local to its mark.
const display = { crosshair: guide, showX: false, digits: 2 }
createPlot(flowHost, { scales: { t, q }, marks: [flow], plugins: [guide, tooltip({ ...display, marks: [flow] })] })
createPlot(rainHost, { scales: { t, rain }, marks: [rain], plugins: [guide, tooltip({ ...display, marks: [rain] })] })
createPlot(areaHost, { scales: { t, flow }, marks: [components], plugins: [guide, tooltip({ ...display, marks: [components] })] })

Public API

const guide = crosshair({
  mode: 'x',
  snap: { mark: observed, axis: 'x' },
  labels: { x: 't', y: 'q' },
})
const interaction = tooltip({ marks: [observed, forecast], crosshair: guide })
const plot = createPlot(host, { scales: { t, q }, marks, plugins: [guide, interaction] })
guide.update({ mode: 'xy' })
guide.update({ snap: { mark: observed, axis: 'y' } })
interaction.update({ position: 'top' })
// A linked crosshair's snap axis takes precedence over tooltip.axis.
// Without a link, the tooltip retains all sample coordinates.
interaction.update({ crosshair: undefined, axis: 'xy' })

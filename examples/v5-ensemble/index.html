v5: ensemble

A 51-member forecast stored once in an ensemble store. The mark draws percentile spread bands, the median and mean, a control member and the individual members. Hover to inspect the nearest member and its statistics; use the legend to toggle each part.

Ensemble options 
const store = createEnsemble({ x: times, members })
const fc = ensemble(store, {
  x: 't', y: 'q', label: 'Forecast',
  spread: { bands: [[5, 95], [25, 75]] },
  median: {}, mean: false, control: { member: 0 },
  members: { opacity: 0.25 },
  exceedance: { threshold: 100 },
})
createPlot(host, { scales, axes, marks: [fc], plugins: [guide, tooltip({ marks: [fc] }), highlight({ marks: [fc] }), legend()] })

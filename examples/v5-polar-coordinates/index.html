v5: polar coordinates

Explore the public polar API with three plots sharing the same bearing and radius settings: clockwise from north, an anticlockwise sector with an intercept, and a radial scale with an inner radius. The projected coordinate readouts show how data values map into each plot.

Phase 1 provides scales, axes, layout and coordinate projection. Data marks are not available yet.

Public API

const bearing = angular({
  domain: [0, 360],
  direction: 'clockwise',
  intercept: 0,
  range: [0, 2 * Math.PI],
})
const distance = radial({ domain: [0, 100], innerRadius: 0.25 })
const plot = createPolarPlot(element, {
  scales: { bearing, distance },
  axes: [
    axis('bearing', { position: 'angular', grid: true }),
    axis('distance', { position: 'radial', grid: true }),
  ],
})
const point = plot.project(45, 70)

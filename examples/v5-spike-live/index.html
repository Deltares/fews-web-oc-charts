v5 spike: shared live data

Two SVG renderers share one 8,192-sample ring buffer and one reactive domain. Their pixel ranges and geometry remain independent. Append batches manually or start a deterministic live stream; old samples are evicted without growing the canonical buffers.

Phase 0 prototype. The example explicitly publishes store versions to the reactive core; automatic store subscriptions and the public shared-scale API are not implemented yet.

v5: shared domains, local ranges

Both plots use the same time and discharge handles. Changing a domain updates both plots; resizing the detail plot changes only its pixel ranges. Destroying the overview leaves the detail plot and shared handles alive.

Drag either plot to pan, scroll to zoom and double-click to reset. One pan and one zoom handle are installed on both plots; the shared scale handles keep them synchronized. Move over either plot to share the crosshair's time and discharge values. Each plot projects those values through its own pixel ranges; leaving hides both guides. Shift-drag to create, move or resize a persistent time selection in either plot. Removing a plot leaves the selection intact. The shared clock below starts stopped; it does not change the chart domains.

const t = time({ domain: [start, end] })
const q = linear({ domain: [0, 100] })
const panning = pan({ mode: 'x' })
const zooming = zoom({ mode: 'x', wheel: 'x' })
const pointer = sharedPointer({ by: 'xy' })
const guides = crosshair({ pointer, labels: { x: 't', y: 'q' } })
const selection = sharedSelection()
const clock = sharedClock({ initial: start }) // stopped until start()
const plugins = () => [
  panning, zooming, guides,
  brush({ mode: 'x', persistent: true, selection }),
]
const overview = createPlot(elA, { scales: { t, q }, axes: [...], plugins: plugins() })
const detail = createPlot(elB, { scales: { t, q }, axes: [...], plugins: plugins() })

subscribe(t.domain, domain => console.log('One notification for both plots', domain))
subscribe(selection.selection, value => console.log('Shared domain ranges', value))
subscribe(clock.time, time => console.log('Shared current time', time))
selection.setSelection(undefined) // explicit clear; plot destruction does not clear
clock.tick()                      // manual refresh from Date.now()
clock.start()                     // one shared timer, not one timer per plot
clock.stop()
t.domain.set([nextStart, nextEnd]) // both plots, independent ranges
panning.update({ mode: 'xy' })      // reconfigures the gesture on both plots
overview.destroy()              // detail and shared handles survive
clock.destroy()                 // application-owned cleanup when finished

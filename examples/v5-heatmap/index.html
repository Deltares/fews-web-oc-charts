v5: heatmap

A time-by-level matrix with explicit irregular cell edges and row-major values. Missing values are transparent. Both plots share one colour scale with a fixed domain: changing its palette recolours both without changing their cell geometry. Hovering a cell reports its bounds and value; the crosshair snaps to that cell. The first heatmap can be hidden directly.

Public API

const color = colorScale({ domain: [0, 20], colors: ['#2166ac', '#f7f7f7', '#b2182b'] })
const grid = createGrid({
  xEdges: [0, 1, 4], yEdges: [0, 2, 8],
  values: new Float32Array([0, 10, NaN, 20]),
})
const mark = heatmap(grid, { scales: { x: 'time', y: 'level' }, color })
color.update({ domain: [0, 30] }) // shared with other heatmaps (and future colorBar)

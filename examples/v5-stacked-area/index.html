v5: stacked areas

Retained SVG layers share diverging data-space endpoints. The first plot has one implicit stack; the second overlays independent observed and forecast stacks. A missing visible value breaks only its own stack, and hiding that layer repairs the gap.

Update retained handles

Both plots share one owned table, retaining the newest twelve samples. All viewport samples and their neighbours are retained, with shared-boundary pixel-bucket LOD for dense views. Canvas, tooltips and a built-in legend are not implemented yet. See the dedicated LOD example for a 24,000-sample stack and live retained-row metrics.

Public API

const flows = createTable({ t, upstream, lateral })
const areas = stackedArea(flows, {
  x: 't',
  scales: { x: 't', y: 'q' },
  layers: [
    { id: 'upstream', y: 'upstream', fill: '#4477aa' },
    { id: 'lateral', y: 'lateral', fill: '#228833' },
  ],
  curve: 'linear', // or 'step' (midpoint steps)
})
// Supply a non-empty stack ID on every layer for independent named stacks.
areas.update({ curve: 'step' })

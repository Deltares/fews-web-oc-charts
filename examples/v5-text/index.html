v5: text marks

Place styled labels at data coordinates on named cartesian scales.

Public API

text({
  x: 't',
  y: 'q',
  xValues: times,
  yValues: values,
  textValues: ['Low', 'Rising', 'Peak', 'Falling', 'Recovered'],
  dy: -10,
  fill: '#7556a8',
  textAnchor: 'middle',
})

v5: brush selection

Hold Shift and drag in the main chart to zoom. Auto mode follows the v4 zoom gesture: stay within 25 pixels of the starting x position to select vertically, or the starting y position to select horizontally. Move beyond both bounds to select both axes.

Brush interaction

Overview navigator

Drag in the overview without a modifier to select a time window. The selection stays visible: drag its interior to move it, or its left/right handles to resize it. Updates zoom the main chart live, while the overview keeps the full 48-hour domain.

Public API

    
const navigator = brush({ mode: 'x', persistent: true, modifier: ModifierKey.None })
navigator.setSelection({ mode: 'x', scales: { t: [visibleStart, visibleEnd] } })
const overview = createPlot(host, {
  scales: { t: overviewTime, q }, axes, marks, plugins: [navigator],
})
let overviewDomain = mainTime.domain.get()
overview.element.addEventListener(brushEvent, (event) => {
  const selection = (event as CustomEvent<BrushSelection>).detail
  mainTime.domain.set(selection.scales.t)
  overviewDomain = mainTime.domain.get()
})
// Follow every domain change, including API updates, without polling input events.
// Skip overview echoes: time rounding must not cancel the active navigator gesture.
subscribe(mainTime.domain, (domain) => {
  if (domain !== overviewDomain) {
    navigator.setSelection({ mode: 'x', scales: { t: domain } })
  }
}, { signal: events.signal })
navigator.setSelection(undefined) // Clear the persistent selection.

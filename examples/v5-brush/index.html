v5: brush selection

Hold Shift and drag inside the plot to select a range. The brush emits a selection event without changing the scale domains.

Brush interaction

Last selection


    
Public API

    
const interaction = brush({ mode: 'x' })
const plot = createPlot(host, { scales: { t, q }, axes, marks, plugins: [interaction] })
plot.element.addEventListener(brushEvent, (event) => {
  const selection = (event as CustomEvent<BrushSelection>).detail
  console.log(selection.scales)
})
interaction.update({ mode: 'xy', modifier: ModifierKey.None })

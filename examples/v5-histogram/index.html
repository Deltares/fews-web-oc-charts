v5: histogram

Unsorted observations are binned into irregular intervals. Interior boundaries belong to the following bin; the final boundary is included. NaN and out-of-domain observations are ignored. Empty bins remain visible in the domain. Both renderers use the existing interval bar path. Hover or move across bins to inspect ranges and normalized values; the crosshair snaps to the same bin, and the legend visibility command hides or restores the histogram.

Update retained histogram

Public API

const data = createTable({ row: [0, 1, 2, 3], sample: [3, 0, 1, NaN] })
const distribution = histogram(data, {
  x: 'sample',
  scales: { x: 'sample', y: 'frequency' },
  bins: [0, 1, 3], // complete bin edges, not interior thresholds
})
distribution.update({ normalization: 'density' })
distribution.update({ bins: 6, domain: [0, 3] })
data.append({ row: [4], sample: [2] })
console.table(distribution.bins)

v5 spike: million-point line

One million samples in a columnar store, rendered as an SVG line using M4 decimation. Drag to preview a pan using cached geometry; release to commit the domain and rebuild the visible window. The controls also work without dragging.

Phase 0 prototype, imported directly from the spike modules. These are example-owned controls and a background grid, not the final v5 axes or interaction API.

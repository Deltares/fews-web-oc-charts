v5: drag to pan

Drag inside the plot to move its visible domain. Choose which scale directions respond and optionally require Ctrl or Shift.

const interaction = pan({ mode: 'x' })
const plot = createPlot(host, { scales: { t, q }, axes, marks, plugins: [interaction] })
interaction.update({ mode: 'xy', modifier: ModifierKey.Ctrl })
plot.update({ plugins: [] }) // disable; plugins: [interaction] enables again
